# Пробная сборка Chromium

В Codemagic: Start new build → main → chromium-capacity-trial
(Chromium capacity trial (up to 110 min)). Запуск только ручной.

Перед запуском проверьте остаток бесплатных минут личного аккаунта:
для этого эксперимента оставьте не менее 110 минут. Billing не включать.
Запускайте один раз; повторную попытку выбираем после анализа отчёта.

Это тест полной цели chrome с ограниченным временем, а не готовое приложение.
На удалённом Mac будут скачаны исходники Chromium и зависимости. На вашем
MacBook исходники и Xcode устанавливать не нужно.

Ограничения: весь workflow до 110 минут; сам скрипт до 100 минут;
загрузка до 60 минут; компиляция до 30 минут, две параллельные задачи.
При остатке диска меньше 15 ГиБ скрипт останавливает активную команду.
Порог проверяется периодически и не является жёсткой дисковой квотой.
Лимит времени включает загрузку инструментов и настройку сборки.

Скрипт использует текущую main Chromium и записывает фактические SHA Chromium
и depot_tools в отчёт. Повтор в другой день может использовать другую ревизию.
Это исходный Chromium без изменений интерфейса. Вход Google не тестируется.
SDK берётся из образа Codemagic; несовместимость станет видна в логах.

После завершения скачайте архив Artifacts и пришлите его в чат.
Внутри reports/chromium-trial/summary.json и отдельные логи стадий.
Отчёт обновляется после каждой стадии. Обычная ошибка команды, нехватка диска
или внутренний таймер сохраняют отчёт; авария самой VM/принудительная отмена
не гарантирует загрузку артефактов.

Красный статус ожидаем, если Chromium не успел собраться: time_limit означает
остановку по времени, low_disk — по диску, failed — ошибку команды.
chrome_target_completed означает успешное завершение цели chrome, но не
проверку запуска браузера. Число записей ninja.log не равно проценту готовности.

Исходники и объектные файлы не загружаются в артефакты и не кешируются.
Продолжить незавершённую компиляцию после этого запуска нельзя; это разовый
замер, по которому решаем, стоит ли настраивать сохранение сборки.

Основание: https://github.com/chromium/chromium/blob/main/docs/mac_build_instructions.md
Используем облегчённую component-сборку без отладочных символов.
