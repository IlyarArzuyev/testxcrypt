# XCrypt: проверка удалённого Mac

Это отдельный диагностический проект, а не готовое приложение XCrypt.
Цель — измерить ресурсы удалённого Mac перед попыткой сборки Chromium.
Исходников XCrypt, заметок, профиля браузера и паролей в пакете нет.

## Запуск

1. Создайте на GitHub отдельный публичный репозиторий `testxcrypt`.
   Этот тест предлагается публиковать под лицензией MIT (LICENSE в пакете).
2. Добавьте содержимое этой папки в корень репозитория: `.cirrus.yml`,
   `ci/probe.py`, `README.md`, `LICENSE`, `.gitignore`.
   ZIP как один файл загружать не нужно. В Finder скрытые файлы показывает
   сочетание Cmd+Shift+точка. Убедитесь, что `.cirrus.yml` появился на GitHub.
3. На https://cirrus-ci.com/ подключите GitHub и разрешите Cirrus доступ
   только к этому тестовому репозиторию.
4. Проверьте доступность бесплатного OSS-лимита для вашего аккаунта.
   Платный план, карту и покупку compute credits для этого теста не подключайте.
   Если бесплатный запуск недоступен, остановитесь и пришлите сообщение сервиса.
5. Откройте сборку репозитория в Cirrus и вручную запустите задачу
   `macOS build capacity probe`. Она настроена на ручной запуск.
6. После выполнения скачайте `reports/report.json` из артефактов `report`
   и пришлите его в чат. Если задача не стартовала, пришлите текст ошибки.

Тест измеряет свободный диск, RAM, число CPU, архитектуру, версии macOS,
Xcode и SDK. Затем компилирует крошечную C++ программу под arm64 и запускает
её на arm64-машине. Каждая команда ограничена 60 секундами.
Тест не скачивает Chromium и не читает переменные окружения, профили или ключи.
В публичном репозитории логи и отчёт могут быть публичными.

Зелёный статус задачи означает, что отчёт создан; смотрите `code` отдельных
проверок: 0 означает успех. Он НЕ означает готовность к сборке Chromium.
На Linux/macOS без Xcode скрипт тоже создаёт отчёт с пропусками/ошибками.

## Что решаем по результату

Проверяем диск и память вместе с настройками выбранной версии Chromium,
совместимость Xcode/SDK, максимальную длительность задачи, остаток бесплатной
квоты и размер артефакта. Только после этого имеет смысл готовить полную сборку.
Для будущей сборки XCrypt потребуется отдельно решить вопрос доступности
его исходников: бесплатный OSS-режим не означает бесплатную сборку закрытого проекта.

Образ Sonoma указан в официальной документации Cirrus, но его доступность
и пригодность SDK для свежего Chromium ещё не подтверждены запуском.
Работа входа Google в ранее испытанном Chromium не гарантирует работу
в изменённом браузере: это проверяется отдельно после сборки.

## Источники (проверены 21 октября 2026)

- Бесплатный OSS-лимит: https://github.com/cirruslabs/cirrus-ci-docs/blob/master/docs/features.md
- macOS-образ: https://github.com/cirruslabs/cirrus-ci-docs/blob/master/docs/guide/macOS.md
- Ручной запуск и артефакты: https://github.com/cirruslabs/cirrus-ci-docs/blob/master/docs/guide/writing-tasks.md
- Сборка Chromium на Mac: https://chromium.googlesource.com/chromium/src/+/main/docs/mac_build_instructions.md

Документация Cirrus описывает бесплатный месячный лимит для OSS, но её страницы
об образе и тарифе обновлялись в 2024 году. Фактическая доступность проверяется
в интерфейсе провайдера; бесплатная полная сборка пока не подтверждена.
