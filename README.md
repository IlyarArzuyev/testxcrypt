# XCrypt: проверка удалённого Mac

Диагностика ресурсов перед попыткой сборки Chromium. Это ещё не сборка XCrypt и не проверка входа Google.

## Запуск через Codemagic

1. Откройте https://codemagic.io/ и зарегистрируйте личный аккаунт (Individual/Personal, не Team).
2. Подключите GitHub с доступом только к IlyarArzuyev/testxcrypt и добавьте этот репозиторий как приложение. Если предлагается тип проекта, выберите Other и настройку через YAML.
3. Проверьте наличие бесплатных минут для macOS M2. Не включайте billing и платный план: бюджет проекта — ноль.
4. Нажмите Start new build, выберите ветку main и workflow macos-capacity-probe (XCrypt Mac capacity probe).
5. После завершения скачайте reports/report.json из артефактов и пришлите его в чат. Если запуск недоступен, пришлите текст ошибки или скриншот.

Конфигурация codemagic.yaml уже находится в корне репозитория. Запуск ручной, автоматические триггеры не настроены. Машина — mac_mini_m2; максимальное время теста — 10 минут. Xcode используется из образа по умолчанию, его фактическая версия записывается в отчёт.

## Что проверяет тест

Свободный диск, память, CPU, архитектуру, версии macOS, Xcode и SDK. Компилирует маленькую программу для arm64 и запускает её на arm64-машине. Chromium не скачивается; профили браузера, заметки, переменные окружения и ключи не читаются.

Зелёный статус означает создание отчёта. Для отдельных проверок code: 0 означает успех. Это не гарантия возможности полной сборки Chromium. Нужно оценить также доступное время, квоту и совместимость SDK с выбранной версией Chromium. Вход Google в изменённом браузере проверяется отдельно.

## Условия и источники

На момент проверки 21 октября 2026 Codemagic описывает 500 бесплатных минут в месяц для личного аккаунта на M2; для Team бесплатные минуты не предусмотрены. Документация YAML указывает предел одной сборки 120 минут. Фактический доступ аккаунта и остаток квоты проверяются перед запуском.
